# Inventario de Elementos del Modelo C4 — SismoReporta AQP
**Construcción de Software · EPIS-UNSA · Semestre 2026-B · Grupo 08**  
Integrantes: Santiago Palma (`spalmaa@unsa.edu.pe`), Dario Rafael Cornejo Hurtado (`dcornejohu@unsa.edu.pe`)

---

El presente inventario consolida todos los actores, límites del sistema, dependencias externas, contenedores de software y componentes modulares definidos en los Laboratorios 04 (Arquitectura) y 05 (Diseño UML 2.5.1). Este documento constituye la fuente formal de verdad para la construcción del modelo único en Structurizr DSL.

| Elemento | Tipo C4 | Descripción Arquitectónica | Origen en Laboratorios Previos |
| :--- | :--- | :--- | :--- |
| **Ciudadano Afectado** | Persona | Habitante de la región Arequipa que experimenta el evento sísmico y reporta daños estructurales, personas atrapadas o vías colapsadas con fotografías y geolocalización GPS. | `docs/architecture/drivers.md` (RF-01, RF-02) |
| **Brigadista en Campo** | Persona | Miembro de rescate (Bomberos, Cruz Roja, Defensa Civil) desplegado en terreno que recibe asignaciones de auxilio y actualiza el estado de atención de víctimas en tiempo real. | `docs/architecture/drivers.md` (RF-04), `docs/design/historia.md` |
| **Coordinador del COE** | Persona | Operador del Centro de Operaciones de Emergencia y Defensa Civil que supervisa el mapa de calor de incidentes, evalúa severidades críticas y despacha cuadrillas. | `docs/architecture/drivers.md` (RF-03), `docs/design/actividades-priorizar-asignar.puml` |
| **SismoReporta AQP** | Sistema de Software | Plataforma integral de gestión de emergencias que absorbe ráfagas masivas de reportes ciudadanos bajo redes móviles colapsadas y coordina el auxilio de brigadas. | `docs/architecture/adr/001-estilo-arquitectonico.md` |
| **Servicio de Mapas y Teselas** | Sistema Externo | Proveedor externo de cartografía base (OpenStreetMap / Mapbox) utilizado para la renderización de mapas vectoriales, capas satelitales y geocodificación inversa. | `docs/architecture/diagramas/despliegue.py`, `docs/design/paquetes.puml` |
| **Pasarela de Alertas SMS / Broadcast** | Sistema Externo | Servicio de telecomunicaciones de emergencia para el envío masivo de alertas de evacuación a terminales móviles en zonas de impacto sísmico severo. | `docs/architecture/diagramas/despliegue.py` (Pushover/SMS Gateway), `docs/design/secuencia-sincronizar-reporte.puml` |
| **PWA Cliente Offline** | Contenedor (Web / Mobile) | Aplicación Web Progresiva instalable en smartphones. Permite el registro de reportes con fotos comprimidas y GPS localmente en IndexedDB sin conexión a red. | `docs/architecture/adr/002-estrategia-offline-pwa.md`, `docs/design/secuencia-sincronizar-reporte.puml` |
| **Tablero Web COE** | Contenedor (Web SPA) | Aplicación web para estaciones de comando del COE. Visualiza mapa de calor geoespacial, clustering de daños y consola de asignación de brigadas. | `docs/architecture/adr/001-estilo-arquitectonico.md`, `docs/architecture/diagramas/despliegue.py` |
| **Proxy Perimetral y Balanceador** | Contenedor (Infraestructura) | Servidor Nginx perimetral que actúa como reverse proxy, gestiona certificados SSL/TLS, compresión Gzip y aplica rate limiting para protección contra saturación. | `docs/architecture/diagramas/despliegue.py`, `README.md` (Lab 04) |
| **API Backend Monolítico** | Contenedor (Aplicación) | Servicio central en Python (FastAPI). Expone APIs REST y WebSockets, orquesta la validación de sintaxis, autenticación y la ingesta inmediata con fast ACK. | `docs/architecture/adr/001-estilo-arquitectonico.md`, `src/sismoreporta/` |
| **Buffer y Broker de Colas** | Contenedor (Almacén de Datos) | Instancia de Redis en memoria que actúa como amortiguador de ráfagas para absorber 20,000 peticiones concurrentes y cola de tareas en segundo plano. | `docs/architecture/adr/001-estilo-arquitectonico.md`, `docs/design/secuencia-sincronizar-reporte.puml` |
| **Worker de Procesamiento Asíncrono** | Contenedor (Aplicación) | Conjunto de workers en segundo plano (Celery/arq) que consumen tareas de Redis: compresión de imágenes, deduplicación espacial y cálculo de prioridad. | `docs/architecture/adr/001-estilo-arquitectonico.md`, `docs/architecture/diagramas/despliegue.py` |
| **Base de Datos Geoespacial** | Contenedor (Almacén de Datos) | Motor relacional PostgreSQL 16 con extensión PostGIS para almacenamiento transaccional seguro y consultas de indexación espacial (R-Tree / GiST). | `docs/architecture/adr/003-base-de-datos-postgis.md`, `docs/design/paquetes.puml` |
| **Almacén de Objetos Multimedia** | Contenedor (Almacén de Datos) | Servidor MinIO (compatible con AWS S3) para la custodia persistente de fotografías comprimidas de colapsos estructurales y evidencias de rescate. | `docs/architecture/diagramas/despliegue.py`, `README.md` (Lab 04) |
| **Componente de Ingesta y Sync** | Componente | Controlador y lógica de negocio responsable de recibir ráfagas diferidas de reportes offline, validar esquemas y emitir ACK HTTP 202 inmediato. | `docs/design/paquetes.puml` (`sismoreporta.ingesta`), `src/sismoreporta/dominio.py` |
| **Componente de Triaje y Severidad** | Componente | Motor analítico que procesa el nivel de daño reportado, aplicando ponderaciones por tipo de colapso y vidas en riesgo para catalogar el incidente. | `docs/design/paquetes.puml` (`sismoreporta.triaje`), `src/sismoreporta/dominio.py` |
| **Componente de Despacho y Brigadas** | Componente | Módulo que gestiona la disponibilidad de cuadrillas de rescate y las asigna a los incidentes de mayor severidad por orden de cercanía geodésica. | `docs/design/paquetes.puml` (`sismoreporta.brigadas`), `docs/design/actividades-priorizar-asignar.puml` |
| **Componente de Servicios GIS** | Componente | Adaptador espacial que ejecuta consultas nativas PostGIS (`ST_DWithin`, `ST_ClusterDBSCAN`) para deduplicar reportes y proyectar mapas de calor. | `docs/design/paquetes.puml` (`sismoreporta.gis`), `src/sismoreporta/dominio.py` |
| **Componente de Notificaciones** | Componente | Orquestador de avisos que emite eventos de actualización por WebSocket al COE y coordina despachos de SMS críticos ante alertas catastróficas. | `docs/design/paquetes.puml` (`sismoreporta.notificaciones`), `docs/design/secuencia-sincronizar-reporte.puml` |
| **Componente de Dominio Compartido** | Componente | Núcleo agnóstico que contiene entidades básicas (`Reporte`, `Coordenadas`, `FotoEvidencia`), enumeraciones de estado y contratos de interfaz. | `docs/design/paquetes.puml` (`sismoreporta.compartido`), `src/sismoreporta/dominio.py` |
